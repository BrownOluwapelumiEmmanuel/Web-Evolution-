Evolution Of Web

🌐 HTML (1991)

Created by: Tim Berners-Lee

HTML known as- Hyper Text Markup Language is the skeleton of every website. It gives structure to content using tags like headings, paragraphs, links, and images tags . It began in 1991 as a way to share text documents across the early web.

🎨 CSS (1996)

Created by: Håkon Wium Lie

CSS is known as the beauty of a website,it handles colors, fonts, spacing, and layout Making the website look fancy and attractive.

💡 JavaScript (1995)

Created by: Brendan Eich

JavaScript is the brain of a webpage, it brings live and interactivity like toggle buttons,forms,animations, games.Despite it being created in just 10days in 1995 it is one of the most important languages in the world.

🐍 Python (1991)

Created by: Guido van Rossum

Python is an high level progamming language known for being easy to read and write but it is powerful and flexible, phython today has great impact in web development-used in web, AI, and automation.

☕ Java (1995)

Created by: James Gosling

Java also known as write once, run anywhere, this is a powerful programming language that runs behind the scenes like in banking apps, games, business system/website.

💻 C++ (1985)

Created by: Bjarne Stroustrup

C++ is a language used to build sofware, games, operating system. C++ language is fast and controls how program or pages should run which is why it's mostly used in heavy performance system.

🔧 C (1972)

Created by: Dennis Ritchie

C is the foundation of many other languages, it is fast and close to hardware, Windows, Linux and MacOS are written in C.
